# 臺灣太空法規總覽 Taiwan Space Law & Regulations

以易讀方式彙整臺灣與國際太空法制的靜態網站,共兩個頁面:

## `index.html` — 臺灣太空法規

- **太空發展法**(母法,2021 公布、2023 修正)— 立法目的、名詞定義、登錄制度、發射許可、發射場域、事故處理、產業促進、罰則
- **國家太空中心設置條例**(2022)— 行政法人 TASA 的組織法
- **四項授權子法**(2022 施行)— 登錄作業、發射許可及太空事故處理、發射場域、民間資訊提供
- **審查基準與收費標準**、其他相關法規(電信管理法、民用航空法、貿易法出口管制)
- 法制沿革時間軸與官方法規連結

## `international.html` — 國際太空法

- **法制沿革時間軸** — 從 1957 史普尼克、1967 外太空條約到 Artemis Accords 與當代議題
- **聯合國五大太空條約** — 外太空條約、營救協定、責任公約、登記公約、月球協定(含締約狀況)
- **外太空條約核心原則** 逐條白話摘要、**聯合國原則宣言**(1963–1996)
- **當代發展** — Artemis Accords、太空資源立法、太空碎片與 LTS 準則、ITU 頻譜、太空交通管理
- **重要意義**與臺灣《太空發展法》內國法化國際原則的連結

> 全站已針對手機優化:導覽列在窄螢幕收成單行可橫向捲動(產業鏈頁的中文/EN 切換固定於右側);區塊間距與字級調整;地圖在觸控裝置改為**雙指移動/縮放**(單指仍可捲動頁面),並隱藏密集標籤、改為點選節點才顯示,放大觸控目標。

## `valuechain.html` — 臺灣太空產業價值鏈地圖(中英雙語)

- **全版面互動地圖(OpenStreetMap 底圖,Leaflet 自架於 `vendor/leaflet/`)** — 9 個產業聚落節點(臺北、新北、基隆七堵、桃園、新竹、苗栗、臺中、臺南、屏東旭海),圓圈以**圓餅圖**依當地五種產業類別的組成比例上色(對照篩選器顏色),點擊檢視當地機構;OSM 圖磚以 CSS 濾鏡轉為深空暗色調;機構清單於地圖下方以多欄卡片呈現
- **每家機構附官方網站連結** — 依當前語言連到對應語系官網(中文頁→中文官網、英文頁→英文官網),方便國際客戶直接連接
- **價值鏈五大環節** — 研究機構、火箭發射、衛星零組件、地面設備、應用服務,可依環節篩選
- 收錄 TASA、中科院、晉陞太空、鴻海、啟碁、穩懋、鐳洋等 23 個代表性機構
- **LEO 衛星元件 × 臺灣供應鏈互動爆炸圖** — 9 大衛星元件(太陽能陣列、ADCS、通訊酬載、推進、TT&C、電源、星載電腦、熱控、影像酬載)逐一標示對應臺灣廠商與供應鏈強度(強/發展中/缺口三級)
- **旗艦任務時間軸** — 福衛五號/七號、獵風者、福衛八號、B5G 低軌通訊衛星
- 右上角 **中文/EN 切換**,語言偏好記憶於 localStorage

設計語言採用「Formosa Cosmos」原則:星塵灰深空底色、南十字星空背景、島嶼稜線地平線、曙光金強調色,中文標題用 Noto Serif TC、數據用 Space Grotesk。

## 發佈方式(GitHub Pages)

單一自包含的 `index.html`,無需建置流程:

1. 到本 repo 的 **Settings → Pages**
2. Source 選擇 **Deploy from a branch**,選取本分支與 `/ (root)` 目錄
3. 儲存後約一分鐘,網站即發佈於 `https://<帳號>.github.io/TASA/`
